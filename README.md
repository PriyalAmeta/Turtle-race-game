# Turtle Race Game

## Overview

The Turtle Race Game is a Python project built using the `turtle` graphics library. It is an interactive race simulation where the user can choose the number of turtles, assign a unique color to each one, and watch them compete in a randomly generated race. Once a turtle reaches the finish line, the winner is displayed on the screen.

This project was created as part of my Python learning journey to strengthen both programming fundamentals and graphical programming concepts.

## Interface Features

The project also focuses on creating a simple graphical interface using Python's Turtle library. Some interface elements include:

* Pastel-themed background
* Multiple user-created turtles with custom colors
* Finish line for the race
* Randomized turtle movement
* On-screen winner announcement
* Organized race layout with evenly spaced turtles
